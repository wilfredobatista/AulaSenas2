# Work Configurador

## Objetivo

Desarrollar y mantener únicamente la aplicación ubicada en `apps/configurador/`.

Esta aplicación captura o importa videos, extrae datos, etiqueta muestras, valida información y organiza los archivos del dataset.

## Límites

Puede trabajar con:
- `apps/configurador/`
- Las rutas de almacenamiento de `data/`.

No debe modificar:
- `apps/usuario/`
- `training/`
- `models/`
- `contracts/`
- Documentación general.

En esta etapa no debe ejecutar tareas, modificar archivos ni crear código. Solo debe comprender este objetivo y sus límites.

## Documentacion de codigo 
Todo código nuevo o modificado debe cumplir la norma de documentación definida en AGENTS.md y skills/comun.md.
