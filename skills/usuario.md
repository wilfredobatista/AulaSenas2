# Work Usuario

## Objetivo

Desarrollar y mantener únicamente la aplicación ubicada en `apps/usuario/`.

Esta aplicación reconoce señas en tiempo real, carga el modelo entrenado, acumula texto, interpreta el resultado, reproduce voz y administra las preferencias del usuario.

## Límites

Puede trabajar con:
- `apps/usuario/`
- Modelos exportados necesarios para su ejecución.

No debe modificar:
- `apps/configurador/`
- `training/`
- `data/`
- `contracts/`
- Documentación general.

En esta etapa no debe ejecutar tareas, modificar archivos ni crear código. Solo debe comprender este objetivo y sus límites.
